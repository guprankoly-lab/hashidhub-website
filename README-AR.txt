HashidHub — تحديث واجهة + ريلز + ترويج + إشعارات

ما الجديد في هذه النسخة:
1) تثبيت ذكي حسب نظام التشغيل
   - أندرويد/كروم: زر تثبيت مباشر (beforeinstallprompt).
   - آيفون: زر يفتح إرشادات «إضافة إلى الشاشة الرئيسية» بخطوة واحدة.

2) إصلاح الريلز
   - إصلاح خطأ: filter is not a function (NodeList → Array).
   - أزرار تفاعل جانبية بأسلوب تيك توك (إعجاب / تعليق / مشاركة / صورة المالك).
   - تشغيل تلقائي عند الظهور مع احترام إعداد الإيقاف.

3) التفاعلات (Long Press)
   - الضغط المطول على زر الإعجاب يفتح منتقي: أعجبني · أحببته · أضحكني · أحزنني · أغضبني.

4) الهيدر
   - إزالة أزرار ليل/خروج/الأشخاص من الشريط.
   - زر ⋯ في أقصى اليسار يفتح قائمة: الوضع الليلي · الإعدادات · الإدارة · تسجيل الخروج.

5) ترويج المنشور
   - خيار «ترويج المنشور» في قائمة ⋯.
   - وسائل دفع يمنية: جوالي · فلوسك · ONE Cash · يمن موبايل · كريمي · أخرى.
   - إرفاق إشعار التحويل + وسيلة تواصل مع المعلن.
   - الطلبات تُحفظ في promoteRequests للمراجعة.

6) الإشعارات الفورية (FCM)
   - تهيئة Firebase Messaging في الواجهة + معالجة push في Service Worker.
   - من الإعدادات: «تفعيل الإشعارات الفورية».
   - لحين ضبط VAPID Key في Firebase Console لن تصل الإشعارات والجهاز مغلق.
   - يمكن تعيين window.__HH_VAPID_KEY قبل التحميل أو لاحقاً من الإعدادات.

7) التشغيل التلقائي
   - افتراضي: مفعّل للفيديوهات والريلز.
   - إيقافه من الإعدادات (⋯ → الإعدادات).

8) الرد على التعليقات
   - زر «رد» ظاهر تحت كل تعليق.
   - تعديل / إخفاء / حذف تظهر بالضغط المطول على التعليق.

9) الإعلانات الممولة
   - أزرار إعجاب ومشاركة على بطاقة الإعلان.

قبل النشر:
1) انشر firestore.rules (تشمل promoteRequests).
2) ارفع الملفات إلى Vercel.
3) لتفعيل FCM الكامل: Firebase Console → Cloud Messaging → Web Push certificates → انسخ VAPID
   ثم في المتصفح: window.__HH_VAPID_KEY = "مفتاحك"
   أو أضفه في الكود عند الحاجة.
4) امسح كاش Service Worker بعد النشر (أو نافذة خاصة).

اختبر: الريلز، زر ⋯، الترويج، الرد على تعليق، تثبيت أندرويد/آيفون، الإعدادات.

==================== تحديث 1.3 ====================
- الدخول بحساب فيسبوك (زر بلون وشعار فيسبوك). يتطلب تفعيل Facebook في Firebase Console →
  Authentication → Sign-in method، وإدخال App ID وApp Secret من developers.facebook.com،
  ثم نسخ رابط OAuth redirect إلى إعدادات تطبيق فيسبوك.
- قائمة أعلى الشاشة: الإعدادات (الخصوصية ورؤية المنشورات / اللغة / الوضع) ← الصفحات ← المجموعات
  ← العضوية المميزة ← الإدارة ← تسجيل الخروج. وأُزيلت خانات الصفحات/المجموعات/العضوية من الرئيسية.
- القصص أكبر ومرتبة (غير المشاهَدة أولاً)، وشريط الريلز مرتب حسب المشاهدات والتفاعل مع أفضلية للأحدث.
- مشغّل ريلز جديد: ملء الشاشة عمودياً، نقرة = تشغيل/إيقاف، نقرتان = إعجاب، شريط تقدم قابل للسحب،
  زر الصوت، تعليقات داخلية، زر رجوع النظام يغلق المشغّل، تحميل مسبق للمقطع التالي، وعدّاد مشاهدات.
- صفحة واحدة ومجموعة واحدة لكل عضو (المميزون والإدارة بلا حد). للتعديل: FREE_PAGE_LIMIT / FREE_GROUP_LIMIT.
- أداء: تحميل كسول للصور، content-visibility للمنشورات، Service Worker بالشبكة أولاً.
- مهم: انشر firestore.rules المحدّثة (تسمح بحقل views في الريلز) وامسح كاش الـ Service Worker.

==================== تحديث 1.6 ====================
- ريلز: تعديل الوصف والغلاف والحذف للمالك، وتظهر في الموجز كمنشور عادي وفي «حسابي» وملف العضو.
- غلاف (صورة مصغّرة) يُلتقط تلقائياً لكل فيديو/ريل عند الرفع، فلا شاشة سوداء. الريلز القديمة بلا غلاف تعرض خلفية بصورة صاحبها.
- ترتيب الريلز: الجديدة (آخر 48 ساعة) أولاً ثم الأعلى مشاهدة وتفاعلاً.
- مشغّل ريلز: تخزين مؤقت للمقاطع (Cache Storage) فتُعاد بلا تحميل، وتحميل مسبق للمقطع التالي، وضغط الريلز إلى ≤8MB لبدء أسرع.
- فيديو الموجز: حجم ثابت، غلاف واضح، لا تشغيل تلقائي، أزرار (تشغيل/إيقاف، شريط تقدم، صوت واحد، ملء الشاشة).
- المنشورات الطويلة تُختصر بسطرين مع «المزيد…»، والتعليقات تُظهر تعليقاً واحداً مع «عرض كل التعليقات».
- معاينة المشاركة (صورة + وصف) عبر الرابط /s/<id>: يلزم رفع api/share.js وإضافة rewrite في vercel.json ونشر firestore.rules.
- تعديل الصفحات (الاسم، الوصف، التصنيف، الشعار، الغلاف) والمجموعات (الاسم، الوصف، الصورة).
- حقول النماذج والتعليقات المكتوبة لم تعد تُمسح عند وصول تحديث لحظي.
